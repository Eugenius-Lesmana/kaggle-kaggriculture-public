# Capacity module smoke, 30 September 2026

Branch: `dev/eugene-codex-capacity`, based on `origin/dev/eugene-claude-routeopt` at `f673cce`. This is an isolated experiment; `CAPACITY_SE_PLOT`, `CAPACITY_GEESE`, and `CAPACITY_TOMATO` all default to `False`.

## Change

- The programme buys SE from day 10 once it has $4,000 plus a $500 reserve. It plans all 24 usable SE cells and routes recovery work to the four previously reserved distant cells.
- With BAKERY or BRUNCH_SPOT open, each shop instance calls for four SE goose slots, capped at six extra slots. Duplicate shop instances count. The existing NE/SW strawberry layout is unchanged.
- With PIZZA_SHOP or FARMERS_MARKET open by day 21, eight SE cells target tomato. Ripe SE wheat is harvested early to release cells for these shop-triggered uses. The tomato block bypasses the generic day-18 crop cutoff through day 21.
- After SE unlock, the programme requests 14 hands. Survival watering, feeding, and mature harvests become more urgent; optional SE wheat planting waits behind them.

## Four-game smoke

`evaluation/routeopt/diag.py`, seeds 8001–8004, one seat, two workers, versus `agents/ours/h1-substrate-metav4/main.py`. The enabled agent was generated by `evaluation/capacity/enable.py`; the generated direct-load file in `.cache/` is not committed. The default-off control used the candidate directly. Both completed all four games without agent runtime errors. After day 6, the diagnostic recorded about one failed field action per game in both arms.

## Verdict

Land acquisition and shop-triggered capacity work. The aggregate unfinished-work count narrowly passes the requested check, but feed, dying-water, and overdue-harvest counts each rise. Late empty cells average 10.7/day with the module versus 7.4/day in the control, so the planting-gap goal is unmet. Own bank falls $8,379/game while opponent bank rises $12,880/game in this four-game smoke. Keep the flags off. This is not evidence to promote the module or to infer an 80-game outcome; it needs a capacity mix and staffing revision before paired evaluation.
